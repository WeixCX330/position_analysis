# metrics.py 全部指标与分布计算说明

本文对应当前 `metrics.py`。真实净值路径与每一条模拟净值路径使用同一套 `path_metrics()` 公式，再由 `summarize()` 汇总模拟总体。

相关文档：[数据与收益转换](data_explained.md)、[估参与路径模拟](backtest_explained.md)、[日期划分](../date_ranges/ranges_explained.md)。

## 1. 先区分三个统计层次

| 层次 | 计算对象 | 输出举例 |
| --- | --- | --- |
| 每一步收益 | 同一条路径的相邻净值 | 某一天简单收益为-2% |
| 单条路径指标 | 该路径从起点到终点的完整序列 | 累计收益、最大回撤、年化波动率 |
| 跨路径分布 | 同一个指标在全部模拟路径上的结果 | 累计收益p05、最大回撤p95、终点损失VaR95 |

比如模拟10000条路径，每条计算一个最大回撤，最终得到10000个最大回撤，再求它们的分位数。不是先画一条平均路径，再算平均路径的最大回撤。

## 2. 指标名称与分位点

```python
METRICS = {
    "total_return": "累计收益",
    "annualized_return": "复合年化收益",
    "maximum_drawdown": "最大回撤",
    "annualized_volatility": "年化波动率",
    "sharpe_ratio": "夏普比率",
    "downside_volatility": "年化下行波动率",
}
QUANTILES = (0.05, 0.25, 0.50, 0.75, 0.95)
```

共有六项逐路径指标。VaR、CVaR、亏损频率和真实结果百分位不是这里的逐路径指标，而是全部路径的总体统计。

除夏普比率外，收益、损失、回撤和波动率均以小数输出：`0.03` 表示3%。夏普比率无量纲。

## 3. path_metrics 的输入形状与校验

```python
def path_metrics(paths, elapsed_years, risk_free_rate=0.0):
    paths = np.asarray(paths, dtype=float)
```

设有 `M` 条路径，每条有 `T + 1` 个净值点，即 `T` 个相邻收益间隔：

```text
paths.shape = (M, T+1)
每一行是一条路径：P_0, P_1, ..., P_T
elapsed_years = 实际起终日期的自然日差 / 365.2425
risk_free_rate = 年化无风险收益率，小数，默认0
```

真实路径传入 `(1, T+1)` 的二维数组；模拟路径通常一批传入最多1000行。

要求输入是二维数组、至少两个净值点、区间年数大于零，且全部净值有限并大于零。否则报错。

这里不读取日期，只接收净值数组与外部计算好的年数，因此不能自行识别交易日缺口。

## 4. 从净值计算每一步简单收益

```python
returns = paths[:, 1:] / paths[:, :-1] - 1
```

`paths[:, 1:]` 取每行第二个点至最后一个点，`paths[:, :-1]` 取第一个点至倒数第二个点，对齐后相除。

```text
R_(j,t) = P_(j,t) / P_(j,t-1) - 1
returns.shape = (M, T)
```

`j` 代表路径，`t` 代表该路径内的观测间隔。以下 `axis=1` 都表示沿一条路径的时间方向计算；返回长度为 `M` 的数组。

注意：此处使用简单收益，不是 `backtest.py` 估参所用的对数收益。

## 5. 区间累计收益 total_return

```python
log_ratio = np.log(paths[:, -1]) - np.log(paths[:, 0])
total = np.expm1(log_ratio)
```

数学公式：

```text
a_j = ln(P_(j,T)) - ln(P_(j,0))
累计收益_j = exp(a_j) - 1 = P_(j,T) / P_(j,0) - 1
```

不是每日简单收益相加，也不是每日收益的算术平均。相邻收益应复利连乘：

```text
1 + 累计收益 = ∏(1 + R_t)
```

`np.expm1(x)` 计算 `exp(x) - 1`，在 `x` 接近0时通常比先 `exp()` 再减1更有数值精度。先分别取两个净值的对数再相减，也避免直接计算极端净值比时的部分数值问题。

该指标只取起终点，但最大回撤等其他指标仍必须使用整条路径。

## 6. 复合年化收益 annualized_return

```python
annual = np.expm1(log_ratio / elapsed_years)
```

设 `Y = elapsed_years`：

```text
复合年化收益 = exp(ln(P_T / P_0) / Y) - 1
             = (P_T / P_0) ** (1 / Y) - 1
```

例如两年累计上涨21%，则年化为 `1.21 ** (1/2) - 1 = 10%`。

这里直接使用 `log_ratio`，不先用 `ln(1 + total)` 还原。原因是终值极小时，浮点累计收益可能被舍入成 `-1`，继续取 `ln(0)` 会丢失信息；直接保留净值的对数比可以避开该问题。

`np.errstate(over="raise", invalid="raise")` 表示年化计算发生溢出或无效运算时抛出错误，不静默输出一个看似可用的数字。

不足一年也会年化。例如假设仅3个自然日从100变为108.9，年数为 `3 / 365.2425`，机械年化约为 `32213.5293`，即约322万%。这说明短期年化可能极不稳定，不是预测未来一年能获得这种收益。

## 7. 年化波动率 annualized_volatility

```python
vol = returns.std(axis=1, ddof=1) * np.sqrt(252)
```

当每条路径至少有两个收益时，先计算简单收益的样本标准差：

```text
R_bar = (R_1 + ... + R_T) / T
s_R = sqrt( Σ(R_t - R_bar)^2 / (T - 1) )
年化波动率 = s_R × sqrt(252)
```

`ddof=1` 指分母使用 `T - 1`，不是 `T`。

如果只有一个收益，样本标准差没有可用的自由度，代码返回 `NaN`。`np.full(len(paths), np.nan)` 为每条路径生成一个空指标。

该年化公式以一年252个观测日、方差可按时间线性缩放为近似前提。代码不按真实缺口天数对单个收益加权，也不做自相关调整。

注意两种不同的“年化波动率”：

- `fit.annual_volatility`：训练期**对数收益**样本标准差乘 `sqrt(252)`，属于模型参数。
- 路径的 `annualized_volatility`：真实或模拟评价期**简单收益**样本标准差乘 `sqrt(252)`，属于路径表现指标。

二者的样本时期和收益定义都不同，不应要求数值完全一致。

## 8. 夏普比率 sharpe_ratio

```python
sharpe = np.divide(
    returns.mean(axis=1) * 252 - risk_free_rate,
    vol,
    out=np.full(len(paths), np.nan),
    where=vol > 0,
)
```

当前公式是：

```text
夏普比率 = (每日简单收益算术平均 × 252 - 年化无风险收益率)
           / 年化简单收益波动率
```

这里分子是算术均值年化，不是复合年化收益。`risk_free_rate` 已经是年化值，直接在年化分子中减去，不再乘252。

例如参数 `risk_free_rate=0.02` 表示年化2%。它只影响夏普，不改变模拟漂移、不从净值扣费，也不改变累计收益。

`out=...` 先把输出全部设置为空；只有 `vol > 0` 时执行除法。零波动率或无法计算波动率的路径，夏普保持 `NaN`，不会返回无穷大。

恒定正收益路径可能有累计收益和零波动率，但本代码的夏普仍不可用。

## 9. 最大回撤 maximum_drawdown

```python
np.max(1 - paths / np.maximum.accumulate(paths, axis=1), axis=1)
```

分解为：

```text
H_t = max(P_0, ..., P_t)            截至t时刻的历史最高净值
D_t = 1 - P_t / H_t                当前相对历史峰值的跌幅
最大回撤 = max(D_0, ..., D_T)
```

`np.maximum.accumulate(..., axis=1)` 从左到右累计记录每条路径历史最高值。再算各时点回撤，最后取最大值。

例子：净值 `100 → 110 → 99 → 108.9`，历史峰值为 `100、110、110、110`，各时点回撤为 `0、0、10%、1%`，所以最大回撤是10%，即 `0.10`。

最大回撤以非负跌幅报告，数值越大表示回撤越深。它不是终点亏损；上述路径终点仍比起点上涨8.9%。

## 10. 年化下行波动率 downside_volatility

```python
np.sqrt(np.mean(np.minimum(returns, 0) ** 2, axis=1) * 252)
```

```text
负向部分_t = min(R_t, 0)
年化下行波动率 = sqrt( [Σ min(R_t, 0)^2 / T] × 252 )
```

这实际上是以0收益为目标的年化下行偏差：

- 上涨日或零收益日记为0；
- 下跌日保留负收益，再平方；
- 分母是全部收益观测数 `T`，不是仅下跌日的数量；
- 不减去负收益的均值，也不使用 `T - 1`；
- 没有减去无风险收益率或其他目标收益。

因此，它不是“只抽出下跌日再求样本标准差”，代码也没有计算 Sortino 比率。

例子：收益 `10%、-10%、10%`，平方负向部分为 `0、0.01、0`：

```text
年化下行波动率 = sqrt((0.01 / 3) × 252)
                 ≈ 0.916515，即91.6515%
```

只有一个收益时也能按该公式计算：若该收益上涨，下行波动率为0；若下跌，等于跌幅绝对值乘 `sqrt(252)`。与样本波动率、夏普的最少样本规则不同，但单样本结果没有稳健统计含义。

## 11. 一条路径的数值核对

对净值 `100 → 110 → 99 → 108.9`：

| 计算项 | 结果 |
| --- | --- |
| 每步简单收益 | `0.10、-0.10、0.10` |
| 每步简单收益均值 | 约 `0.03333333` |
| 每步简单收益样本标准差 | 约 `0.11547005` |
| 累计收益 | `0.089`，即8.9% |
| 最大回撤 | `0.10`，即10% |
| 年化波动率 | 约 `1.83303028`，即183.3030% |
| 夏普，无风险收益为0 | 约 `4.58257569` |
| 年化下行波动率 | 约 `0.91651514`，即91.6515% |

复合年化收益还取决于传入的实际年数，不能仅凭这四个净值确定。上述高波动示例只用于核对公式。

## 12. distribution：先过滤不可用值

```python
finite = np.asarray(values)[np.isfinite(values)]
```

输入一般是一个指标在所有模拟路径上的一维结果。过滤该指标的 `NaN` 或无穷值，只对有限结果求分布。

如果10000条路径有100条该指标无效，该指标的 `sample_count` 就是9900，不补0。不同指标有效样本数可能不同。

如果一条有限结果都没有，返回 `available=False` 和原因文本。当前原因文本固定写为“少于2个日收益或波动为零”，它是常见情况说明，不是函数逐一检查后得出的唯一故障原因。

## 13. 分位数的具体算法

```python
float(np.quantile(finite, q))
```

按 `QUANTILES` 输出：`p05、p25、p50、p75、p95`。键名使用：

```python
f"p{int(q * 100):02d}"
```

先把0.05乘100转为整数5，再补足两位，得到 `p05`。`p50` 是中位数，不是均值。

当前调用未指定 `method`，使用 NumPy 默认的线性插值。排序后设有效样本数为 `N`，零基索引：

```text
h = (N - 1) × q
i = floor(h)
w = h - i
Q(q) = (1-w) × x_i + w × x_(i+1)
```

若恰好落在某个索引上，就取该值；端点按最小值或最大值处理。例如数列 `0、0.1、0.2、0.3` 的25%分位为 `0.075`。

分位数含义取决于指标方向：

- 累计收益p05：模拟结果中偏低的收益。
- 最大回撤p95：模拟路径中偏大的回撤。
- 这些是模拟情景分位数，不是参数估计的95%置信区间，也不是模型已经校准的未来发生概率。

## 14. 直方图 histogram

```python
counts, edges = np.histogram(finite, bins=32)
```

将该指标有效样本划成32个等宽箱，返回33个边界和32个计数。未指定 `density=True`，所以 `counts` 是条数，不是概率或概率密度。

通常每箱左边界包含、右边界不包含，最后一箱包含最右边界。总计数等于有效样本数。若要显示经验比例，需要另行用各箱计数除以 `sample_count`。

若全部样本相等，NumPy 会为直方图扩展取值范围；所有分位数仍等于该常数，并不意味着存在非零样本波动。

## 15. summarize：定义回测区间终点损失

```python
losses = -metrics["total_return"]
```

对每条模拟路径，令区间终点累计收益为 `C_j`：

```text
L_j = -C_j
```

累计亏损10%对应损失 `0.10`；累计盈利10%对应损失 `-0.10`。负损失是正常定义，不能自动截成0。

**这里是整个回测区间的终点累计损失，不是单日损失，也不是路径最大回撤。** 一年档得到一年区间终点损失风险，一个月档得到一个月区间终点损失风险。

这与独立极值理论工具的“单日损失POT VaR/ES”期限不同，不能直接按同名字段横向比较。

## 16. VaR 的计算

```python
var = float(np.quantile(losses, confidence))
```

默认 `confidence=0.95`，取所有路径终点损失的95%分位数，算法与上面的线性插值相同。

```text
VaR_95 = Q_0.95(-累计收益)
```

在这里的分位数定义下，等价于累计收益p05取负，允许微小浮点差异。若收益p05为-8%，VaR95为8%；若收益p05仍为正2%，VaR95为-2%，不会截为0。

`confidence` 改变 VaR/CVaR 的尾部水平，不改变固定输出的五个指标分位点。

## 17. CVaR 的计算及样本边界

```python
tail = losses[losses >= var]
cvar_loss = float(tail.mean())
```

先选损失大于或等于 VaR 的路径，再对这些路径损失做算术平均：

```text
A = {j : L_j >= VaR}
CVaR = Σ(L_j, j∈A) / |A|
```

这是经验尾部平均的实现，可能为负。没有把低于 VaR 的样本纳入平均。

例如损失样本为 `-20%、-10%、0%、10%、20%`：95%线性插值分位为18%，只有20%损失进入尾部，所以 CVaR 为20%。

样本有限且阈值附近有重复值时，由于使用 `>=` 并纳入全部等于 VaR 的路径，尾部条数不一定刚好等于5%。本实现没有做边界样本的分数权重校正，因此不应宣称它始终等于严格积分定义的有限样本ES。

该函数本身不做 Bootstrap 置信区间，也不是用 GPD 外推尾部。

## 18. 亏损路径频率 loss_frequency

```python
float(np.mean(metrics["total_return"] < 0))
```

布尔判断中，亏损为 `True=1`，非亏损为 `False=0`，取均值就是路径数量占比：

```text
亏损频率 = 终点累计收益严格小于0的路径数 / 总路径数
```

收益恰好为0不计为亏损。这个指标不关心途中是否跌过；途中大幅回撤、最终盈利的路径不计入终点亏损。

它是给定模型、参数和历史起点下的模拟频率，不是经过校准的客户实际亏损概率。

## 19. 真实收益所在模拟百分位 actual_percentile_rank

```python
float(np.mean(metrics["total_return"] <= actual["total_return"]))
```

```text
真实收益百分位 = 模拟累计收益 <= 真实累计收益的路径数 / 总路径数
```

范围0到1。比如结果 `0.12` 表示12%的模拟终点收益不高于真实收益，真实结果位于模拟偏低的一侧。

这里用经验累计比例，不使用分位数插值，且相等的路径全部计入。它不是“真实收益比模拟中位数低12%”，也不是模型准确率或统计检验p值。

## 20. 返回值及异常边界

`path_metrics()` 返回六个长度为路径数的一维数组。`distribution()` 将其中一项转成有限样本分布。`summarize()` 返回：

| 字段 | 含义 |
| --- | --- |
| `metric_distributions` | 六项逐路径指标各自的五档分位和直方图 |
| `loss_frequency` | 模拟区间终点累计亏损的路径比例 |
| `var_confidence` | VaR/CVaR 使用的置信水平 |
| `var_loss` | 区间终点损失分位数 |
| `cvar_loss` | 损失不低于 VaR 的路径平均损失 |
| `actual_percentile_rank` | 真实累计收益对应的模拟经验累计比例 |

真实指标中的非有限值在 `evaluate_period()` 中转为 `None`，最终写 JSON 为 `null`；模拟指标在 `distribution()` 中过滤非有限值。

`summarize()` 对累计收益的 VaR、CVaR、频率和真实百分位没有再调用有限值过滤。正常流程依赖上游的正净值及数值检查；极端溢出输入不能假定一定被本函数完整兜底。

## 21. 需要牢牢记住的口径

- 模型训练用对数收益；本文件的波动率、夏普和下行波动率用简单收益。
- 复合年化收益依据实际自然日年数；波动率和夏普按252个观测日年化。
- 最大回撤使用完整路径；累计收益、亏损频率及VaR/CVaR关注终点。
- 五个分位数描述模拟路径的指标分布，不是对未来准确率的证明。
- 所有真实结果都是产品净值表现，不包含客户申赎时点、持仓金额或个性化费用。
